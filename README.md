## ✨ Features & Highlights

- 🤖 **Farhan AI Assistant (Intelligent Portfolio Chatbot)**: Built-in context-aware AI chatbot with zero-latency response engine, synthetic Web Audio chime, quick-prompt chips, and direct interactive action triggers (scrolling to sections, downloading CV, or opening WhatsApp).
- 🌊 **ReactBits WebGL Fluid Splash Cursor**: High-performance, GPU-accelerated fluid dynamic simulation cursor with blooming colors and curling vortex ripples.
- 🧊 **3D Interactive Physics & Specular Glare**: Real physical 3D perspective tilt (`preserve-3d`), dynamic multi-depth parallax layers (`translateZ`), and mouse-tracking specular light sheen on cards.
- 🎬 **Canvas Scroll Animation**: Smooth frame-by-frame canvas sequence animation synchronized with user scroll.
- 💎 **Modern Frosted Glassmorphism**: Clean dark-mode aesthetic with backdrop blur filters, beveled rim lighting, and elegant glowing accents.
- 💼 **Professional Path Timeline**: Career chronicle featuring 3D embossed logo badges for PT Bank Rakyat Indonesia, KPU, DPRD Kab. Cirebon, and Printing Mediaku.
- 🚀 **Featured Projects with Interactive Slideshow**:
  - **SOCA** — PT BRI Merchant Monitoring & Productivity Analytics Platform
  - **Bagja** — Reward & Lucky Draw Generator Platform (BRI Region 9)
  - **BIMORA** — Digital QR Attendance & Student Management System
  - **OurMoment** — Digital Wedding & Event Invitation SaaS Platform
  - **Creative Celebrations** — Interactive Birthday & Corporate Dedication Websites
- 📱 **Fully Responsive**: Seamlessly optimized across Mobile, Tablet, Laptop, and Ultra-Wide displays.

## 🚀 Running Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/hansaefulah/portfoliohanss.git
   ```
2. Place the folder into your local web server (e.g., `xampp/htdocs/portfoliohanss`) or open with VS Code Live Server.
3. Open `http://localhost/portfoliohanss/` or `http://127.0.0.1:5500/index.html` in your browser.
